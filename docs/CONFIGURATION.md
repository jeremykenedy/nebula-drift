# Configuration

Settings are changed from the TV's Nebula Drift app entry. Controls are large,
focusable buttons intended for a D-pad remote. Each press advances the selected
setting; the last fixed value advances to Random. Randomize all settings and Use
fixed settings are available at the top of the screen.

| Setting | Values | Effect |
|---|---|---|
| Color palette | Violet, Blue, Emerald, Crimson | Changes both cloud color layers. |
| Nebula structure | Veils, Pillars, Supernova, Dark matter | Changes the procedural cloud formation. |
| Drift speed | Very low through Very high | Changes the rate of cloud drift and meteor movement. |
| Cloud density | Very low through Very high | Changes how much glowing gas fills the scene. |
| Star density | Very low through Very high | Changes the background star field density. |
| Brightness | Very low through Very high | Scales scene luminance. |
| Star twinkle | Off or On | Enables slow variation in star brightness. |
| Meteor trails | Off or On | Enables occasional diagonal light trails. |

Every setting can be randomized independently. Random choices are resolved once
when the app preview or DreamService starts. The saved selection remains Random
and is resolved again the next time the scene starts.
