# Changelog

Notable changes to Nebula Drift are listed here.

## 1.0.0

- Initial release for Fire TV, Android TV, and Google TV devices running Android API 23 or newer.
- Added an animated procedural nebula DreamService with four color palettes and four cloud structures.
- Added remote-operated settings, per-setting random choices, and a local settings provider for host applications.
- Added checksum-verifying install, update, restore, and uninstall commands.
- Runtime has no network permission, ads, analytics, tracking, or reporting.
- First release. Install the APK and checksum from the release; there is no earlier version to upgrade.
